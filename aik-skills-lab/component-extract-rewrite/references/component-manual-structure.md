# 组件手册 10 章结构

## 结构定义

```
# 组件手册：{组件名称}

## 1. 组件概述
   - 功能描述
   - 技术特征
   - 适用场景

## 2. 架构设计
   - 包结构
   - 分层映射
   - 设计模式

## 3. 类与接口清单
   - 核心类
   - 扩展点

## 4. 核心流程
   - 时序图
   - 事务边界
   - 异步处理

## 5. 配置与依赖
   - 外部 Maven 依赖
   - 内部依赖
   - 配置属性

## 6. 业务耦合清单
   - 耦合 ID
   - 位置
   - 类型
   - 脱敏建议

## 7. 敏感数据清单
   - 敏感 ID
   - 位置
   - 类型
   - 处理方式

## 8. 脱敏与复写指导
   - 命名映射表
   - 抽象化策略
   - 配置外化清单

## 9. 使用指南
   - 快速开始
   - 配置说明
   - 扩展示例

## 10. 附录
    - 源文件清单
    - 依赖树
    - 变更历史
```

## 两种粒度的差异

| 方面 | 技术方案级 | 组件级 |
|------|-----------|--------|
| 萃取范围 | 多个关联类、配置、中间件 | 单个类或少量紧密关联的类 |
| 手册侧重点 | 方案全局架构、技术选型理由、组件协作关系 | 核心算法、接口设计、参数说明 |
| 流程设计 | 多组件交互时序图 | 单组件内部流程 |
| 脱敏指导 | 跨组件依赖抽象化 | 单组件参数化 |

## 质量门禁

- 手册必须覆盖全部 10 章
- 耦合清单必须精确到方法级别，脱敏建议必须具体可操作
- 敏感数据检测零容忍，全部标注
- 手册产出前必须通过 design-review-checker 审核

## 3 个人工检查点

### 检查点1：范围确认

- 回显用户指定的文件/包/方法列表
- 确认粒度级别（技术方案级 / 组件级）
- 确认组件用途描述
- 询问是否补充遗漏

### 检查点2：分析报告审核

- 展示架构模式、耦合清单、敏感数据、依赖关系
- 询问是否补充遗漏的耦合点
- 询问是否有误判

### 检查点3：组件手册最终审批

- 展示手册关键指标（耦合点数量、敏感数据数量、类清单）
- 选项：A) 批准保存  B) 修订内容  C) 仅保存暂不复写
