# 命名规范

> 来源：aIk-coding-style 规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 类名 | 大驼峰 | `XrayDetectionRecord` |
| 方法名 | 小驼峰 | `findPage`, `createRecords` |
| 变量名 | 小驼峰 | `groupData`, `typeImages` |
| 常量 | 全大写下划线 | `MAX_FILE_SIZE` |
| 包名 | 全小写 | `com.example.module` |
| Service Bean | `{module}.{ServiceName}` 或 `{module}.{subModule}.{ServiceName}` | `module.EntityService` 或 `module.sub.EntityService` |
| 表名 | 下划线小写 | `lb_module_entity` |
| 字段名 | 下划线小写 | `field_name` |
