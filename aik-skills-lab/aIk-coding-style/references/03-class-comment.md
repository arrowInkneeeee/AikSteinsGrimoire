# 类注释规范

> 来源：aIk-coding-style 规范 · 类级别注释格式与要求

### 标准格式
```java
/**
 * -anchor {类描述}
 *
 * @author a I k .
 * @version 1.0.0
 * @implNote JDK 8
 * @apiNote
 * @since {yyyy/MM/dd}
 * -
 */
```

### 说明
- `-anchor` 和结尾的 `-` 是固定标记
- `@author` 固定为 `a I k .`（注意空格和点号）
- `@implNote` 固定为 `JDK 8`
- `@since` 使用日期格式 `yyyy/MM/dd`
