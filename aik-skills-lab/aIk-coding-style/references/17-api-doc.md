# API文档规范

> 来源：aIk-coding-style 规范

- 位置：`{module}/api/`
- 文件名：`{module}-api.md`
- 包含：请求头、请求体、响应示例、错误码

## 强制规范

- **每个接口必须同时包含请求示例和响应示例**，缺一不可
- GET 单参数接口（如 `/orders/findById?id=1`）虽无 Body 请求体，仍需在参数表格的"示例"列中填写示例值，并必须提供响应示例
- POST / PUT 接口必须提供完整的 JSON 请求示例（包含所有必填字段），不得省略
- 响应示例必须覆盖成功场景（HTTP 200），建议同时覆盖常见错误场景（如 400、401、404、业务错误码）
- 请求/响应示例中的字段值必须是真实可用的测试数据（如 `1`、`"2024-03-18 10:30:00"`），禁止使用 `xxx`、`test` 等无意义占位符
