## 七、安全修复模式参考

### SQL 注入修复

```java
// 错误：${} 拼接
@Select("SELECT * FROM T_ORDER WHERE ORDER_NO = '${orderNo}'")

// 正确：#{} 参数化
@Select("SELECT * FROM T_ORDER WHERE ORDER_NO = #{orderNo}")

// 动态排序：白名单校验
private static final Set<String> ALLOWED_SORT_FIELDS = Set.of("CREATE_TIME", "TOTAL_AMOUNT");
if (!ALLOWED_SORT_FIELDS.contains(sortField)) {
    throw new BusinessException("非法排序字段");
}
```

### 越权修复

```java
// 错误：未校验数据归属
mapper.selectById(id);

// 正确：校验数据归属
lambdaQuery()
    .eq(Entity::getId, id)
    .eq(Entity::getUserId, UserContext.getCurrentUserId())
    .one();
```

### 敏感数据修复

```java
// 密码存储：BCrypt 加密
user.setPassword(passwordEncoder.encode(password));

// 日志脱敏
log.info("手机号: {}", DesensitizeUtil.mobilePhone(phone));

// 返回值脱敏
@Desensitize(type = DesensitizeType.ID_CARD)
private String idCard;
```

### 防重放 / 防刷

```java
// 幂等键防重放
String key = "idempotent:" + dto.getIdempotentKey();
if (redisTemplate.hasKey(key)) {
    throw new BusinessException("重复提交");
}

// 限流防刷
@RateLimiter(key = "#phone", limit = 1, period = 60)
```
