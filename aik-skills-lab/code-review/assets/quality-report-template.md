## 七、通用修复模式

### N+1 查询修复模式

```java
// 问题：循环中查询数据库
for (Long id : ids) {
    Entity entity = mapper.selectById(id);  // N 次查询
}

// 修复：使用批量查询
List<Entity> entities = mapper.selectBatchIds(ids);
Map<Long, Entity> entityMap = entities.stream()
    .collect(Collectors.toMap(Entity::getId, Function.identity()));
```

### 空指针修复模式

```java
// 修复：使用 Optional 处理可能为 null 的值
return Optional.ofNullable(mapper.selectById(id))
    .map(this::convertToVO)
    .orElseThrow(() -> new BusinessException("数据不存在"));
```

### 事务修复模式

```java
// 修复：缩小事务范围，将外部调用移出事务
@Transactional
public void saveOrder(OrderDTO dto) {
    orderMapper.insert(order);  // 仅数据库操作在事务内
}

public void processOrder(OrderDTO dto) {
    saveOrder(dto);             // 事务操作
    sendNotification(dto);     // 非事务操作
}
```
