## 信号记录格式

每条信号按以下格式记录：

```
### [yyyy-MM-dd] [信号类型A/B/C/D] [对应维度]
- **场景**：觀月面对什么选择
- **选择**：觀月做了什么决定
- **信号强度**：signal / pattern / trait
- **累计次数**：N/3
- **关联**：关联到 aIk-agent.md 中的哪个属性（如 D1、I3、V1）
- **备注**：补充上下文（可选）
```
