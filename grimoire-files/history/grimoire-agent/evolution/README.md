# 进化机制 — 启用说明

> 版本：v3.0 | 日期：2026-10-09
> 进化机制是**可选的**。觀月可随时说"开启进化模式"或"关闭进化模式"。

---

## 启用 / 关闭

| 指令 | 效果 |
|------|------|
| "开启进化模式" | 綾雾彌奈在每个任务单元结束时输出信号摘要 + UpdateMemory 暂存 |
| "关闭进化模式" | 停止输出信号摘要和暂存，归档功能仍可用 |
| 默认状态 | **关闭**（v3.0 起改为可选，不再强制） |

---

## 启用后的行为

### 支柱 1：强制对话结论

每当完成一个明确的任务单元（功能交付/设计稿/问题解答），在回答末尾追加信号摘要。

**信号摘要模板**（唯一维护点）：

```
---
**📋 本次对话信号摘要**
- 决策记录（如有）：
  - [领域] [具体决策] [结果：被接受/被纠正]
- 纠正信号（如有）：
  - [用户原话] → [推断的偏好]
- 新偏好观察（如有）：
  - [具体行为] → [推断的偏好]
- 无新信号：[是/否]

→ 如需归档到进化日志，下次和我（默认智能体）说"记录一下"
---
```

**硬性要求**：
1. 必须输出：即使无新信号也要输出"本次无新信号"
2. 只输出，不写文件：摘要在对话中可见，归档由默认智能体执行
3. 可当场纠正：用户看到摘要后可立即说"这个观察不对"

### 支柱 2：用户驱动归档 + 兜底提醒

**主路径**：用户下次和默认智能体对话时，说"记录一下" + 简单描述。

**兜底**：信号摘要输出后，綾雾彌奈调用 UpdateMemory 暂存：

| 字段 | 值 |
|------|----|
| `action` | `create` |
| `category` | `task_summary_experience` |
| `title` | `未归档信号 - [日期] - [简要主题]` |
| `content` | 信号摘要的完整内容 |
| `keywords` | `未归档,信号,[领域关键词]` |
| `source` | `auto` |

默认智能体在后续对话中发现"未归档信号"标题的记忆条目时，主动提醒用户归档。归档完成后删除该记忆条目。
