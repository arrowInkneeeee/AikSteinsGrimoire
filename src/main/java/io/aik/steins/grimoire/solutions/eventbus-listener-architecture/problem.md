# 问题描述

## 背景

在多实体关联的业务系统（如 LIMS）中，一个业务操作往往需要触发一系列级联变更：

- 任务状态 → 样品检测状态 → 委托单状态
- 同步实验数据、生成处置任务、记录操作日志、同步设备结果…

## 传统方案的痛点

如果在 Service 层硬编码所有联动逻辑：

1. **强耦合**：一个 Service 方法要感知所有下游影响
2. **难扩展**：新增联动逻辑必须修改已有 Service
3. **难维护**：业务变更时改动面大
4. **难测试**：Service 方法承担了过多职责

## 目标

- 发布者与监听器完全解耦
- 新增联动逻辑无需修改已有代码
- 支持精确的执行阶段控制（前置/核心/后置）
- 异常隔离，单个监听器失败不影响其他
